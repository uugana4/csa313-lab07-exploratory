# BUG-05: POST /api/books буруу JSON-д 400 биш 200 OK буцаадаг

Орчин:  Уншлагын жагсаалт v2.0, curl, macOS, 2026-11-26
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Терминалд ажиллуулна:
   curl -i -X POST localhost:3000/api/books -H "Content-Type: application/json" -d '{bad json'
2. Хариуны статус код болон биеийг харна.
3. Дараа нь `curl -i localhost:3000/api/books`-оор ном нэмэгдсэн эсэхийг шалгана.

Хүлээгдэж байсан: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.»
Бодит үр дүн:     HTTP/1.1 200 OK, биеэр {"result":"OK"}. Гэтэл дараагийн GET-д ном нэмэгдээгүй (4 ном хэвээр), өөрөөр хэлбэл сервер хүсэлтийг чимээгүй орхиод «OK» гэж хэлсэн.

Ноцтой байдал: Major. Клиент амжилттай хадгалагдсан гэж андуурах тул өгөгдөл алдагдана.
